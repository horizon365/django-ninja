# मदद / मदद पाना

## क्या आपको Django Ninja पसंद है?

अगर आपको यह project पसंद है, तो एक छोटा-सा काम आप कर सकते हैं जिससे हमें पता चलेगा कि हम सही दिशा में बढ़ रहे हैं।

बस <a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a> पर django-ninja को एक star दे दीजिए। <a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

या इस URL को social media पर share करें:

```
https://django-ninja.cn
```


## हमारी मदद करना चाहते हैं?

Pull requests का हमेशा स्वागत है।

आप हमारे documentation में typos और spelling की गलतियाँ जाँच सकते हैं, और एक pull request बना सकते हैं या कोई issue खोल सकते हैं।

अगर आपके पास Django Ninja को बेहतर बनाने के लिए कोई सुझाव हैं, तो कृपया उन्हें GitHub पर issues के रूप में बनाएँ।
