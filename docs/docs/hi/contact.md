## क्या आपको Django Ninja पसंद है?

यदि आपको यह project पसंद है, तो एक छोटी सी चीज़ है जो आप हमें बताने के लिए कर सकते हैं कि हम सही दिशा में बढ़ रहे हैं।

बस django-ninja को <a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a> पर एक star दें। <a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

या इस URL को social media पर share करें:

```
https://django-ninja.cn
```

## चीनी community से जुड़ें

एक ऐसे व्यक्ति के रूप में जो वहाँ रह चुका है, मुझे उम्मीद है कि मैं आपको कुछ घुमावदार रास्तों से बचने में मदद कर सकूँ। यदि आप नहीं चाहते कि सीखने के दौरान study materials न मिलने या उत्तर न मिलने की निराशा को दोबारा झेलना पड़े और कुछ दिनों बाद छोड़ देना पड़े, तो यहाँ मैं कुछ Django Ninja learning resources share कर रहा हूँ जिनसे उम्मीद है कि वे आपको आगे बढ़ने में मदद करेंगे।

### एक full-stack developer बनने की कोशिश करें
Backend development के 8 साल बाद, frontend सीखने में मुझे केवल 3 महीने लगे।

Frontend जानने से आप एक independent developer बनने से एक कदम और करीब आ जाते हैं, और APIs को integrate करते समय आपको अधिक आत्मविश्वास मिलता है।

# Site owner से संपर्क करें
इस site के सभी अनुवाद हाथ से किए गए हैं, जिनमें बहुत अधिक समय और मेहनत लगाई गई है, बस सबसे सटीक और उच्चतम गुणवत्ता वाला अनुभव प्रदान करने के लिए।
Development costs से परे, site की domain और server costs वर्तमान में मैं स्वयं वहन कर रहा हूँ, इसलिए site के दीर्घकालिक अस्तित्व और अपडेट सभी के समर्थन पर निर्भर करते हैं। यदि मेरे काम ने आपकी मदद की है और आप मुझे एक coffee देना चाहते हैं, तो आपका **दान** मुझे लगातार अपडेट करने के लिए सबसे बड़ी प्रेरणा होगी:

Alipay
![django-ninja.alipay](img/django-ninja.alipay.jpg)

WeChat
![django-ninja.webchat](img/django-ninja.webchat.jpg)
