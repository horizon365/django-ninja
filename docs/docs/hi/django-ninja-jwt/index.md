[Django Ninja REST framework](https://github.com/vitalik/django-ninja) के लिए एक JSON Web Token authentication plugin।

------------------------------------------------------------------------

Ninja JWT, Django Ninja REST framework के लिए एक JSON Web Token authentication backend प्रदान करता है।
यह रूढ़िवादी default features के एक समूह की पेशकश करके JWT के सबसे सामान्य use cases को कवर करने का लक्ष्य रखता है।
यह तब भी आसानी से extensible होने के लिए designed किया गया है जब कोई आवश्यक feature उपलब्ध न हो।

Acknowledgements
------

यह project Django Ninja REST framework के लिए JSON Web Tokens implement करने के लिए [SIMPLE JWT](https://github.com/jazzband/djangorestframework-simplejwt) से code लेता है।
हालाँकि, मैंने SIMPLE JWT license को `license` folder में शामिल किया है।
