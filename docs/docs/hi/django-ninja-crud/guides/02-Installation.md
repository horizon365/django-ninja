## 👀 Prerequisites

`django-ninja-crud` package को install करने से पहले, सुनिश्चित करें कि निम्नलिखित dependencies installed हैं:

- **Python**: इस package के लिए Python 3.8 या उससे अधिक की आवश्यकता है। यदि आपको Python install या upgrade करने की आवश्यकता है, तो आप इसे [आधिकारिक Python website](https://www.python.org/downloads/) से कर सकते हैं।
- **Django**: इस package के लिए Django 3.2 या उससे अधिक की आवश्यकता है। यदि आपको Django install या upgrade करने की आवश्यकता है, तो आप निम्नलिखित command का उपयोग कर सकते हैं:
- ```shell
  pip install --upgrade django
  ```
- **Django Ninja**: इस package के लिए Django Ninja 0.21 या उससे अधिक की आवश्यकता है। यदि आपको Django Ninja install या upgrade करने की आवश्यकता है, तो आप निम्नलिखित command का उपयोग कर सकते हैं:
- ```shell
  pip install --upgrade django-ninja
  ```

## ⚒️  `django-ninja-crud` इंस्टॉल करना

एक बार जब आप prerequisites install कर लें, तो आप pip का उपयोग करके `django-ninja-crud` install कर सकते हैं:


```shell
pip install django-ninja-crud[testing]
```

यदि installation के दौरान आपको कोई समस्या आती है, तो कृपया [हमसे संपर्क करें](https://github.com/hbakri)।
