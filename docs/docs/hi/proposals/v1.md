# v1 में संभावित बदलाव

Django Ninja का इस्तेमाल दर्जनों कंपनियाँ और visitors पहले से कर रहे हैं, और download statistics के अनुसार यह बढ़ रहा है।

इस स्थिति में, ऐसे बदलाव करना अस्वीकार्य है जो मौजूदा users को अपना code बदलने (या उसे तोड़ने) के लिए मजबूर करें।

दूसरी ओर, शुरुआत में लिए गए कुछ निर्णय अच्छी तरह काम नहीं किए। ये breaking changes version 1.0.0 में introduce किए जाएँगे।

## v1 में संभावित बदलाव

 - **Authentication** एक callable की जगह एक class interface होगा (async authenticators को support देने के लिए)
 - **Response** में **code/headers/body** का support (एक सामान्य response class की तरह)
 - **Router paths** अभी automatically **"/" के साथ join** होते हैं - कुछ मामलों में इसकी ज़रूरत नहीं हो सकती, क्योंकि router prefix एक subfolder की बजाय एक prefix की तरह काम करेगा।
