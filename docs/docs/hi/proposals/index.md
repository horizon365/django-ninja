# Enhancement proposals

Enhancement proposals, **Django Ninja framework** को बड़े feature requests प्रस्तावित करने का एक औपचारिक तरीका हैं।

आप [`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals) के अंतर्गत एक नए page के साथ pull request खोलकर, या [github पर issue](https://github.com/vitalik/django-ninja/issues) खोलकर एक proposal बना सकते हैं।
