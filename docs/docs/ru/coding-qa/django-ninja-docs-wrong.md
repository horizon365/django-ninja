Странная проблема на странице документации django ninja: два разных эндпоинта открываются одновременно
==========================================================

Недавно один из участников сообщества сообщил о проблеме: на странице документации при клике на любой из двух эндпоинтов открываются оба одновременно. Остальные API ведут себя иначе.

![django-ninja-docs-wrong](/img/docs-wrong.png)


В итоге первопричина была найдена: дублировались имена функций или пути. Иными словами, при написании view функция была скопирована, а её имя забыли изменить.
