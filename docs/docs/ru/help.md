# Помощь / Как получить помощь

## Вам нравится Django Ninja?

Если вам нравится этот проект, есть одна маленькая вещь, которую вы можете сделать, чтобы дать нам понять, что мы движемся в правильном направлении.

Просто поставьте django-ninja звезду на <a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a>. <a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

Или поделитесь этой ссылкой в социальных сетях:

```
https://django-ninja.cn
```


## Хотите помочь нам?

Pull request'ы всегда приветствуются.

Вы можете проверить нашу документацию на опечатки и орфографические ошибки, а затем создать pull request или открыть issue.

Если у вас есть предложения по улучшению Django Ninja, пожалуйста, оформите их как issues на GitHub.



## Нужна помощь?

Не стесняйтесь. Перейдите на <a href="https://github.com/vitalik/django-ninja/issues" target="_blank">GitHub issues</a> и опишите вашу проблему или затруднение. Мы постараемся решить их как можно скорее.
