# Потенциальные изменения в v1

Django Ninja уже используют десятки компаний и посетителей, и, судя по статистике загрузок, он растёт.

На данном этапе внесение изменений, которые заставили бы текущих пользователей менять свой код (или сломали бы его), недопустимо.

С другой стороны, некоторые решения, принятые изначально, показали себя не очень хорошо. Эти критические изменения будут внесены в версии 1.0.0.

## Вероятные изменения в v1

 - **Аутентификация** станет интерфейсом классов вместо вызываемого объекта (для поддержки асинхронных аутентификаторов)
 - **Response** для поддержки **code/headers/body** (как общий класс ответа)
 - **Пути Router** в настоящее время автоматически **дополняются "/"** — в некоторых случаях это может быть не нужно, так как префикс роутера будет действовать как префикс, а не как подпапка.
