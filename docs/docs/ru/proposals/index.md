# Предложения по улучшению

Предложения по улучшению — это формальный способ вносить крупные запросы новых возможностей в **фреймворк Django Ninja**.

Вы можете создать предложение, открыв pull request с новой страницей в [`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals) или открыв [issue на github](https://github.com/vitalik/django-ninja/issues).
