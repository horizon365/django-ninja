
Ninja JWT поставляется с приложением, которое предоставляет функциональность чёрного списка токенов.
Чтобы использовать это приложение, включите его в список установленных приложений в `settings.py`:

```python
# Django project settings.py

...

INSTALLED_APPS = (
    ...
    'ninja_jwt.token_blacklist',
    ...
)
```

Также убедитесь, что вы выполнили `python manage.py migrate`, чтобы применить миграции приложения.

Если приложение чёрного списка обнаружено в `INSTALLED_APPS`, Ninja JWT будет добавлять все сгенерированные refresh-токены или sliding-токены в список невыполненных (outstanding) токенов.
Оно также будет проверять, перед тем как считать какой-либо refresh-токен или sliding-токен валидным, что токен отсутствует в чёрном списке токенов.

Приложение чёрного списка Ninja JWT использует две модели: `OutstandingToken` и `BlacklistedToken` для реализации своих списков невыполненных и заблокированных токенов.
Для обеих моделей определены админ-модели. Чтобы добавить токен в чёрный список, найдите соответствующую запись `OutstandingToken` в админке,
затем снова воспользуйтесь админкой, чтобы создать запись `BlacklistedToken`, указывающую на запись `OutstandingToken`.

В качестве альтернативы вы можете добавить токен в чёрный список, создав экземпляр подкласса `BlacklistMixin` и вызвав метод `blacklist` у этого экземпляра:

```python
from ninja_jwt.tokens import RefreshToken

token = RefreshToken(base64_encoded_token_string)
token.blacklist()
```

Это создаст уникальную запись невыполненного токена и запись чёрного списка для claim `jti` токена или для того claim, который указан в настройке `JTI_CLAIM`.

Приложение чёрного списка также предоставляет команду управления `flushexpiredtokens`, которая удалит все истёкшие токены как из списка невыполненных токенов, так и из чёрного списка.
Вам следует настроить на своём сервере или хостинговой платформе задание cron, которое запускает эту команду ежедневно.
