Плагин аутентификации на основе JSON Web Token для [Django Ninja REST framework](https://github.com/vitalik/django-ninja).

------------------------------------------------------------------------

Ninja JWT предоставляет бэкенд аутентификации на основе JSON Web Token для Django Ninja REST framework.
Он стремится охватить наиболее распространённые сценарии использования JWT, предлагая консервативный набор функций по умолчанию.
Он также спроектирован так, чтобы его можно было легко расширять, когда требуемая функциональность отсутствует.

Благодарности
------

Этот проект заимствует код из [SIMPLE JWT](https://github.com/jazzband/djangorestframework-simplejwt) для реализации JSON Web Tokens для Django Ninja REST framework.
Тем не менее, я включил лицензию SIMPLE JWT в папку `license`.
