Документация Django Ninja CRUD
=======================

![Django Ninja CRUD](../img/django-ninja-crud-cover.JPG)


Django Ninja CRUD — это мощный, декларативный, но слегка opinionated фреймворк, который упрощает разработку CRUD-эндпоинтов (Create, Read, Update, Delete) с Django Ninja, а также предоставляет декларативный, сценарный подход к тестированию этих эндпоинтов с помощью Django REST Testing (младшего брата этого пакета)🐣. Он позволяет определять общие эндпоинты как class-based views и легко настраивать их в соответствии с соглашениями вашего проекта, а также легко создавать собственные кастомные views и объявлять их вместе с предоставленными CRUD-views, способствуя тем самым модульности и расширяемости. Этот пакет поощряет фокусировку на самом важном: решении реальных задач, а не изобретении велосипеда по всему проекту.


Изначально вдохновлённый ModelViewSet из DRF, Django Ninja CRUD развился, чтобы устранить его ограничения, приняв подход композиции вместо наследования для достижения истинной модульности — основополагающего шага к более широкому декларативному интерфейсу создания эндпоинтов.


Основные проблемы viewsets, основанных на наследовании:

*     Уникальность CRUD-эндпоинтов для каждой модели: Django Ninja CRUD позволяет определять несколько эндпоинтов для одной и той же модели, обеспечивая версионирование или альтернативные представления.
*     Гибкость кастомизации: вместо переопределения методов в монолитном классе отдельные views настраиваются через композицию и конфигурацию.
*     Неявные связи внутри иерархий наследования: композиция развязывает views, уменьшая зависимости и улучшая повторное использование.
*     Недостаток модульности для новых эндпоинтов: добавление кастомных эндпоинтов больше не требует наследования всего viewset, что упрощает постепенное внедрение новых функций.

✨ Ключевые особенности
-------

*     Полностью декларативный: определяйте views и тесты, объявляя, что вы хотите получить, а не как это сделать.
*     Непревзойдённая модульность: настраивайте viewsets нужными CRUD-views, изменяя поведение каждого view.
*     Лёгкая расширяемость: создавайте собственные кастомные views и используйте их как переиспользуемые компоненты вместе с предоставленными CRUD-views.
*     Сценарный фреймворк тестирования: используйте сценарный фреймворк тестирования, чтобы декларативно и лаконично определять разнообразные тест-кейсы.
*     Фокус на главном: тратьте больше времени на решение реальных задач и меньше — на общие, повторяющиеся задачи.

> **
> Django Ninja CRUD — это больше, чем инструмент; это смена парадигмы в разработке и тестировании веб-приложений на Django.**
