## 👀 Предварительные требования

Перед установкой пакета `django-ninja-crud` убедитесь, что у вас установлены следующие зависимости:

- **Python**: этому пакету требуется Python 3.8 или выше. Если вам нужно установить или обновить Python, вы можете сделать это с [официального сайта Python](https://www.python.org/downloads/).
- **Django**: этому пакету требуется Django 3.2 или выше. Если вам нужно установить или обновить Django, вы можете использовать следующую команду:
- ```shell
  pip install --upgrade django
  ```
- **Django Ninja**: этому пакету требуется Django Ninja 0.21 или выше. Если вам нужно установить или обновить Django Ninja, вы можете использовать следующую команду:
- ```shell
  pip install --upgrade django-ninja
  ```

## ⚒️  Установка `django-ninja-crud`

После того как вы установили предварительные требования, вы можете установить `django-ninja-crud` с помощью pip:


```shell
pip install django-ninja-crud[testing]
```

Если вы столкнулись с какими-либо проблемами при установке, пожалуйста, [свяжитесь с нами](https://github.com/hbakri).
