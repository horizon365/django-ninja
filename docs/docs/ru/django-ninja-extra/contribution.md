**Руководство по вкладу**
=========

  
Спасибо за то, что рассматриваете возможность внести вклад в NinjaExtra! Ваши вклады помогают сделать проект лучше для всех. Прежде чем начать, пожалуйста, уделите момент ознакомлению со следующими рекомендациями.

  
Настройка среды разработки
---------

1.    
    Сделайте форк репозитория: сделайте форк репозитория NinjaExtra на GitHub и клонируйте его локально.
    
2.    
    Виртуальное окружение: создайте и активируйте виртуальное окружение для проекта.
    
        python -m venv venv
        source venv/bin/activate  # Linux/macOS
        
    
        python -m venv venv
        .\venv\Scripts\activate  # Windows
        
    
3.    
    Установите `flit`: убедитесь, что `flit` установлен глобально.
    
        pip install flit
        
    
4.    
    Установите зависимости: установите библиотеки для разработки и pre-commit-хуки.
    
        make install-full
        

### **Стиль кода и форматирование**

*     
    Форматирование: чтобы отформатировать код и обеспечить единообразие, выполните:
    
        make fmt
        
    
*     
    Линтеры: NinjaExtra использует `mypy` и `ruff` для линтинга. Выполните следующую команду, чтобы проверить синтаксис кода:
    
        make lint
        

### **Тестирование**

*     
    Юнит-тесты: мы используем `pytest` для юнит-тестирования. Запустите набор тестов:
    
        make test
        
    
*     
    Покрытие тестами: чтобы проверить покрытие тестами:
    
        make test-cov
        

### **Отправка Pull Request**

1.    
    Ветка: создайте новую ветку для вашей функциональности или исправления бага.
    
        git checkout -b feature-branch
        
    
2.    
    Сообщения коммитов: следуйте спецификации conventional commit для сообщений коммитов.
    
3.    
    Отправьте изменения: отправьте вашу ветку в ваш форкнутый репозиторий.
    
        git push origin feature-branch
        
    
4.    
    Pull request: откройте pull request в ветку `master` репозитория NinjaExtra. Предоставьте понятный заголовок и описание ваших изменений.
