# Help / Getting help

## Do you like Django Ninja?

If you like this project, there is one small thing you can do to let us know we are heading in the right direction.

Just give django-ninja a star on <a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a>. <a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

Or share this URL on social media:

```
https://django-ninja.cn
```


## Want to help us?

Pull requests are always welcome.

You can check our documentation for typos and spelling mistakes, and create a pull request or open an issue.

If you have any suggestions to improve Django Ninja, please create them as issues on GitHub.



## Need help?

Don't hesitate. Go to <a href="https://github.com/vitalik/django-ninja/issues" target="_blank">GitHub issues</a> and describe your problem or difficulty. We will try to resolve them as soon as possible.
