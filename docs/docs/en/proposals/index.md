# Enhancement proposals

Enhancement proposals are a formal way to propose large feature requests to the **Django Ninja framework**.

You can create a proposal by opening a pull request with a new page under [`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals), or by opening an [issue on github](https://github.com/vitalik/django-ninja/issues).
