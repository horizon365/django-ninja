# Potential v1 changes

Django Ninja is already used by dozens of companies and visitors, and from the download statistics, it is growing.

At this point, introducing changes that would force current users to change their code (or break it) is unacceptable.

On the other hand, some decisions made initially did not work well. These breaking changes will be introduced in version 1.0.0.

## Likely changes in v1

 - **Authentication** will be a class interface instead of a callable (to support async authenticators)
 - **Response** to support **code/headers/body** (like a general response class)
 - **Router paths** currently automatically **join with "/"** - in some cases this may not be needed, as the router prefix will act as a prefix rather than a subfolder.

## Your thoughts/proposals

Please give your thoughts/likes/dislikes in the [github issue](https://github.com/vitalik/django-ninja/issues/146).
