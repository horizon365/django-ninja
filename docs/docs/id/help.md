# Bantuan / Mendapatkan bantuan

## Apakah Anda menyukai Django Ninja?

Jika Anda menyukai proyek ini, ada satu hal kecil yang bisa Anda lakukan untuk memberi tahu kami bahwa kami sedang berada di jalur yang benar.

Cukup berikan bintang (star) untuk django-ninja di <a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a>. <a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

Atau bagikan URL ini di media sosial:

```
https://django-ninja.cn
```


## Ingin membantu kami?

Pull request selalu kami nantikan.

Anda dapat memeriksa dokumentasi kami untuk menemukan typo dan kesalahan ejaan, lalu membuat pull request atau membuka issue.

Jika Anda memiliki saran untuk meningkatkan Django Ninja, silakan buat saran tersebut sebagai issue di GitHub.



## Butuh bantuan?

Jangan ragu. Kunjungi <a href="https://github.com/vitalik/django-ninja/issues" target="_blank">GitHub issues</a> dan jelaskan masalah atau kesulitan Anda. Kami akan berusaha menyelesaikannya sesegera mungkin.
