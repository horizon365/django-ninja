### Coba menjadi full-stack developer
Setelah 8 tahun pengembangan backend, belajar frontend hanya butuh 3 bulan.

Mengenal frontend membawa Anda selangkah lebih dekat menjadi developer yang mandiri, dan memberi Anda lebih banyak keyakinan saat mengintegrasikan API.
