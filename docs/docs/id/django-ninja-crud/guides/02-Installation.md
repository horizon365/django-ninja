## 👀 Prasyarat

Sebelum menginstall package `django-ninja-crud`, pastikan Anda telah menginstall dependensi berikut:

- **Python**: Package ini membutuhkan Python 3.8 atau lebih tinggi. Jika Anda perlu menginstall atau meng-upgrade Python, Anda dapat melakukannya dari [situs resmi Python](https://www.python.org/downloads/).
- **Django**: Package ini membutuhkan Django 3.2 atau lebih tinggi. Jika Anda perlu menginstall atau meng-upgrade Django, Anda dapat menggunakan perintah berikut:
- ```shell
  pip install --upgrade django
  ```
- **Django Ninja**: Package ini membutuhkan Django Ninja 0.21 atau lebih tinggi. Jika Anda perlu menginstall atau meng-upgrade Django Ninja, Anda dapat menggunakan perintah berikut:
- ```shell
  pip install --upgrade django-ninja
  ```

## ⚒️  Menginstall `django-ninja-crud`

Setelah prasyarat terinstall, Anda dapat menginstall `django-ninja-crud` menggunakan pip:


```shell
pip install django-ninja-crud[testing]
```

Jika Anda menemui masalah apa pun selama instalasi, silakan [hubungi kami](https://github.com/hbakri).
