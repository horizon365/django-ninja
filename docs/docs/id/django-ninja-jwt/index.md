Plugin autentikasi JSON Web Token untuk [Django Ninja REST framework](https://github.com/vitalik/django-ninja).

------------------------------------------------------------------------

Ninja JWT menyediakan backend autentikasi JSON Web Token untuk Django Ninja REST framework.
Proyek ini bertujuan untuk mencakup use case JWT yang paling umum dengan menawarkan sekumpulan fitur default yang konservatif.
Proyek ini juga dirancang agar mudah diperluas ketika fitur yang dibutuhkan belum tersedia.

Penghargaan
------

Proyek ini meminjam kode dari [SIMPLE JWT](https://github.com/jazzband/djangorestframework-simplejwt) untuk mengimplementasikan JSON Web Tokens untuk Django Ninja REST framework.
Namun, saya telah menyertakan lisensi SIMPLE JWT di folder `license`.
