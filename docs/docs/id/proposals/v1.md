# Perubahan potensial di v1

Django Ninja sudah digunakan oleh puluhan perusahaan dan pengunjung, dan dari statistik unduhan, jumlahnya terus bertumbuh.

Pada titik ini, memperkenalkan perubahan yang memaksa pengguna saat ini mengubah kode mereka (atau merusaknya) adalah hal yang tidak dapat diterima.

Di sisi lain, beberapa keputusan yang diambil di awal ternyata tidak berjalan dengan baik. Perubahan-perubahan yang bersifat breaking ini akan diperkenalkan pada versi 1.0.0.

## Perubahan yang kemungkinan besar di v1

 - **Authentication** akan menjadi interface class alih-alih sebuah callable (untuk mendukung authenticator async)
 - **Response** untuk mendukung **code/headers/body** (seperti class response umum)
 - **Router paths** saat ini otomatis **digabung dengan "/"** - dalam beberapa kasus hal ini mungkin tidak diperlukan, karena prefix router akan berperan sebagai prefix alih-alih subfolder.
