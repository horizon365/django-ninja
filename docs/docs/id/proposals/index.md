# Proposal peningkatan (enhancement proposals)

Proposal peningkatan adalah cara formal untuk mengajukan permintaan fitur besar kepada **framework Django Ninja**.

Anda dapat membuat proposal dengan membuka pull request berisi halaman baru di bawah [`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals), atau dengan membuka [issue di github](https://github.com/vitalik/django-ninja/issues).
