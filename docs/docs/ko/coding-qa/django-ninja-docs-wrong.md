django ninja docs 페이지의 이상한 문제: 서로 다른 두 엔드포인트가 동시에 열림
==========================================================

최근 한 커뮤니티 회원이 문제를 제보했습니다: docs 페이지에서 두 엔드포인트 중 어느 하나를 클릭해도 둘 다 동시에 열리는 현상입니다. 다른 API에서는 이런 동작이 발생하지 않습니다.

![django-ninja-docs-wrong](/img/docs-wrong.png)


결국 근본 원인을 찾아냈습니다: 함수 이름이나 경로가 중복되어 있었던 것입니다. 즉, 뷰를 작성할 때 함수를 복사한 후 이름을 바꾸는 것을 잊은 경우입니다.
