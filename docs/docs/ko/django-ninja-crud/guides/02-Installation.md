## 👀 전제 조건

`django-ninja-crud` 패키지를 설치하기 전에 다음 종속성이 설치되어 있는지 확인하세요:

- **Python**: 이 패키지에는 Python 3.8 이상이 필요합니다. Python을 설치하거나 업그레이드해야 하는 경우 [공식 Python 웹사이트](https://www.python.org/downloads/)에서 할 수 있습니다.
- **Django**: 이 패키지에는 Django 3.2 이상이 필요합니다. Django를 설치하거나 업그레이드해야 하는 경우 다음 명령을 사용할 수 있습니다:
- ```shell
  pip install --upgrade django
  ```
- **Django Ninja**: 이 패키지에는 Django Ninja 0.21 이상이 필요합니다. Django Ninja를 설치하거나 업그레이드해야 하는 경우 다음 명령을 사용할 수 있습니다:
- ```shell
  pip install --upgrade django-ninja
  ```

## ⚒️  `django-ninja-crud` 설치

전제 조건을 설치한 후 pip를 사용하여 `django-ninja-crud`를 설치할 수 있습니다:


```shell
pip install django-ninja-crud[testing]
```

설치 중 문제가 발생하면 [문의해 주세요](https://github.com/hbakri).
