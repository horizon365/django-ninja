# 기능 개선 제안

기능 개선 제안(enhancement proposal)은 **Django Ninja 프레임워크**에 큰 기능 요청을 제안하는 공식적인 방법입니다.

[`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals) 아래에 새 페이지를 추가하는 pull request를 열거나, [github에서 issue](https://github.com/vitalik/django-ninja/issues)를 열어 제안을 만들 수 있습니다.

현재 제안된 내용을 확인해 보세요:

 - [클래스 기반 operations](cbv.md)
