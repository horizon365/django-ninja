# v1에서 변경될 가능성이 있는 사항

Django Ninja는 이미 수십 개의 회사와 방문자들이 사용하고 있으며, 다운로드 통계를 보면 계속 성장하고 있습니다.

시점상으로, 현재 사용자들에게 코드 변경(또는 코드 깨짐)을 강요하는 변경 사항을 도입하는 것은 용납될 수 없습니다.

반면, 초기에 내려진 일부 결정은 잘 작동하지 않았습니다. 이러한 breaking change들은 버전 1.0.0에서 도입될 예정입니다.

## v1에서 변경될 가능성이 있는 사항

 - **Authentication**은 호출 가능한 객체 대신 클래스 인터페이스가 될 예정입니다 (async 인증기를 지원하기 위함)
 - **Response**가 **code/headers/body**를 지원할 예정입니다 (일반 response 클래스처럼)
 - **Router paths**는 현재 자동으로 **"/"와 결합됩니다** - 어떤 경우에는 이것이 필요하지 않을 수 있으며, 이때 router prefix는 하위 폴더가 아닌 접두사처럼 동작합니다.
