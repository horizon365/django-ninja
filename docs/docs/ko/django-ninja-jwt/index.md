[Django Ninja REST 프레임워크](https://github.com/vitalik/django-ninja)를 위한 JSON Web Token 인증 플러그인입니다.

------------------------------------------------------------------------

Ninja JWT는 Django Ninja REST 프레임워크를 위한 JSON Web Token 인증 백엔드를 제공합니다.
보수적인 기본 기능 세트를 통해 JWT의 가장 일반적인 사용 사례를 다루는 것을 목표로 합니다.
또한 필요한 기능이 존재하지 않을 때 쉽게 확장할 수 있도록 설계되었습니다.

감사의 말
------

이 프로젝트는 Django Ninja REST 프레임워크를 위해 JSON Web Token을 구현하기 위해 [SIMPLE JWT](https://github.com/jazzband/djangorestframework-simplejwt)의 코드를 차용했습니다.
다만 `license` 폴더에 SIMPLE JWT 라이선스를 포함시켰습니다.
