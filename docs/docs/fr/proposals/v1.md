# Changements potentiels pour la v1

Django Ninja est déjà utilisé par des dizaines d'entreprises et de visiteurs, et d'après les statistiques de téléchargement, il est en croissance.

À ce stade, introduire des changements qui forceraient les utilisateurs actuels à modifier leur code (ou qui le casseraient) est inacceptable.

D'un autre côté, certaines décisions prises au départ n'ont pas bien fonctionné. Ces changements incompatibles seront introduits dans la version 1.0.0.

## Changements probables dans la v1

 - **Authentication** deviendra une interface de classe au lieu d'un appelable (pour prendre en charge les authentificateurs asynchrones)
 - **Response** prendra en charge **code/headers/body** (comme une classe de réponse générale)
 - **Router paths** actuellement **fusionnés automatiquement avec "/"** - dans certains cas, cela peut ne pas être nécessaire, car le préfixe du router agira comme un préfixe plutôt que comme un sous-dossier.
