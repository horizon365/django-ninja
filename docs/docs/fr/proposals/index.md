# Propositions d'amélioration

Les propositions d'amélioration sont un moyen formel de proposer des demandes de fonctionnalités majeures au **framework Django Ninja**.

Vous pouvez créer une proposition en ouvrant une pull request avec une nouvelle page sous [`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals), ou en ouvrant une [issue sur GitHub](https://github.com/vitalik/django-ninja/issues).
