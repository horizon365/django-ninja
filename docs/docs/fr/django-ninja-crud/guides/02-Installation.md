## 👀 Prérequis

Avant d'installer le paquet `django-ninja-crud`, assurez-vous que les dépendances suivantes sont installées :

- **Python** : Ce paquet nécessite Python 3.8 ou supérieur. Si vous devez installer ou mettre à niveau Python, vous pouvez le faire depuis le [site officiel de Python](https://www.python.org/downloads/).
- **Django** : Ce paquet nécessite Django 3.2 ou supérieur. Si vous devez installer ou mettre à niveau Django, vous pouvez utiliser la commande suivante :
- ```shell
  pip install --upgrade django
  ```
- **Django Ninja** : Ce paquet nécessite Django Ninja 0.21 ou supérieur. Si vous devez installer ou mettre à niveau Django Ninja, vous pouvez utiliser la commande suivante :
- ```shell
  pip install --upgrade django-ninja
  ```

## ⚒️  Installation de `django-ninja-crud`

Une fois les prérequis installés, vous pouvez installer `django-ninja-crud` à l'aide de pip :


```shell
pip install django-ninja-crud[testing]
```

Si vous rencontrez des problèmes lors de l'installation, veuillez [nous contacter](https://github.com/hbakri).
