Un plugin d'authentification JSON Web Token pour le [framework REST Django Ninja](https://github.com/vitalik/django-ninja).

------------------------------------------------------------------------

Ninja JWT fournit un backend d'authentification JSON Web Token pour le framework REST Django Ninja.
Il vise à couvrir les cas d'utilisation les plus courants de JWT en offrant un ensemble conservateur de fonctionnalités par défaut.
Il est également conçu pour être facilement extensible lorsqu'une fonctionnalité requise n'est pas présente.

Remerciements
------

Ce projet emprunte du code à [SIMPLE JWT](https://github.com/jazzband/djangorestframework-simplejwt) pour implémenter les JSON Web Tokens pour le framework REST Django Ninja.
Cependant, j'ai inclus la licence de SIMPLE JWT dans le dossier `license`.
