# Aide / Obtenir de l'aide

## Aimez-vous Django Ninja ?

Si vous aimez ce projet, il y a une petite chose que vous pouvez faire pour nous indiquer que nous allons dans la bonne direction.

Donnez simplement une étoile à django-ninja sur <a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a>. <a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

Ou partagez cette URL sur les réseaux sociaux :

```
https://django-ninja.cn
```


## Vous voulez nous aider ?

Les pull requests sont toujours les bienvenues.

Vous pouvez relire notre documentation à la recherche de coquilles et de fautes d'orthographe, puis créer une pull request ou ouvrir une issue.

Si vous avez des suggestions pour améliorer Django Ninja, veuillez les créer sous forme d'issues sur GitHub.



## Besoin d'aide ?

N'hésitez pas. Rendez-vous sur les <a href="https://github.com/vitalik/django-ninja/issues" target="_blank">issues GitHub</a> et décrivez votre problème ou votre difficulté. Nous nous efforcerons de les résoudre dès que possible.
