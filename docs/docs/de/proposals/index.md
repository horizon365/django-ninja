# Verbesserungsvorschläge

Verbesserungsvorschläge sind ein formeller Weg, um große Funktionsanfragen an das **Django-Ninja-Framework** zu richten.

Sie können einen Vorschlag einreichen, indem Sie einen Pull Request mit einer neuen Seite unter [`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals) öffnen oder ein [Issue auf GitHub](https://github.com/vitalik/django-ninja/issues) eröffnen.

Sehen Sie sich die aktuellen Vorschläge an:
