# Mögliche Änderungen in v1

Django Ninja wird bereits von Dutzenden Unternehmen und Besuchern genutzt, und laut den Download-Statistiken wächst es.

Zu diesem Zeitpunkt wäre es unvertretbar, Änderungen einzuführen, die bestehende Benutzer zwingen würden, ihren Code zu ändern (oder ihn zu brechen).

Andererseits haben sich einige anfangs getroffene Entscheidungen nicht bewährt. Diese breaking changes werden in Version 1.0.0 eingeführt.

## Wahrscheinliche Änderungen in v1

 - **Authentifizierung** wird eine Klassenschnittstelle statt eines Callables sein (um asynchrone Authentifikatoren zu unterstützen)
 - **Response** zur Unterstützung von **Code/Headers/Body** (wie eine allgemeine Response-Klasse)
 - **Router-Pfade** werden derzeit automatisch **mit „/" verbunden** — in manchen Fällen ist das nicht nötig, da das Router-Präfix als Präfix statt als Unterordner fungieren soll.
