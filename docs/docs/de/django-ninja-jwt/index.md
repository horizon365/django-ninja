Ein JSON-Web-Token-Authentifizierungs-Plugin für das [Django Ninja REST framework](https://github.com/vitalik/django-ninja).

------------------------------------------------------------------------

Ninja JWT stellt ein JSON-Web-Token-Authentifizierungs-Backend für das Django Ninja REST framework bereit.
Es zielt darauf ab, die häufigsten Anwendungsfälle von JWT durch einen konservativen Satz an Standardfunktionen abzudecken.
Es ist außerdem so konzipiert, dass es sich leicht erweitern lässt, wenn eine benötigte Funktion nicht vorhanden ist.

Danksagungen
------

Dieses Projekt übernimmt Code von [SIMPLE JWT](https://github.com/jazzband/djangorestframework-simplejwt), um JSON Web Tokens für das Django Ninja REST framework zu implementieren.
Die Lizenz von SIMPLE JWT habe ich jedoch im Ordner `license` beigefügt.
