# Hilfe / Hilfe erhalten

## Mögen Sie Django Ninja?

Wenn Ihnen dieses Projekt gefällt, gibt es eine kleine Sache, mit der Sie uns zeigen können, dass wir auf dem richtigen Weg sind.

Geben Sie django-ninja einfach einen Stern auf <a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a>. <a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

Oder teilen Sie diese URL in sozialen Medien:

```
https://django-ninja.cn
```


## Möchten Sie uns helfen?

Pull Requests sind jederzeit willkommen.

Sie können unsere Dokumentation nach Tipp- und Rechtschreibfehlern durchsuchen und einen Pull Request erstellen oder ein Issue öffnen.

Wenn Sie Vorschläge zur Verbesserung von Django Ninja haben, erstellen Sie diese bitte als Issues auf GitHub.



## Brauchen Sie Hilfe?

Zögern Sie nicht. Gehen Sie zu den <a href="https://github.com/vitalik/django-ninja/issues" target="_blank">GitHub issues</a> und beschreiben Sie Ihr Problem oder Ihre Schwierigkeit. Wir werden versuchen, sie so schnell wie möglich zu lösen.
