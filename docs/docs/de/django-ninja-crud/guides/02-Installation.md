## 👀 Voraussetzungen

Bevor Sie das Paket `django-ninja-crud` installieren, stellen Sie sicher, dass die folgenden Abhängigkeiten installiert sind:

- **Python**: Dieses Paket erfordert Python 3.8 oder höher. Wenn Sie Python installieren oder aktualisieren müssen, können Sie dies von der [offiziellen Python-Website](https://www.python.org/downloads/) tun.
- **Django**: Dieses Paket erfordert Django 3.2 oder höher. Wenn Sie Django installieren oder aktualisieren müssen, können Sie den folgenden Befehl verwenden:
- ```shell
  pip install --upgrade django
  ```
- **Django Ninja**: Dieses Paket erfordert Django Ninja 0.21 oder höher. Wenn Sie Django Ninja installieren oder aktualisieren müssen, können Sie den folgenden Befehl verwenden:
- ```shell
  pip install --upgrade django-ninja
  ```

## ⚒️  Installation von `django-ninja-crud`

Sobald Sie die Voraussetzungen installiert haben, können Sie `django-ninja-crud` mit pip installieren:


```shell
pip install django-ninja-crud[testing]
```

Wenn Sie während der Installation auf Probleme stoßen, [kontaktieren Sie uns](https://github.com/hbakri) bitte.
