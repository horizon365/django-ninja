django ninja ドキュメントページのある奇妙な問題：2 つの異なるエンドポイントが同時に開いてしまう
==========================================================

最近、コミュニティのメンバーからある問題が報告されました。ドキュメントページ上で、2 つのエンドポイントのどちらをクリックしても、両方が同時に開いてしまうというものです。他の API ではこのような挙動は起こりません。

![django-ninja-docs-wrong](/img/docs-wrong.png)


最終的に根本原因を突き止めました。関数名またはパスが重複していたのです。つまり、view を書く際に関数をコピーしたものの、名前を変更し忘れていたということです。
