## 説明

### 希望年収

「965 スケジュール、12 か月分の給与、住宅積立金の全額納付」を基準として、希望年収を入力すると、標準の時給と標準の月給が算出されます。

### 1 日の労働時間

プリセット：965、995、995.5、996。カスタムの労働時間にも対応しています。たとえば Tencent の「水曜健康デー」のようなケースです。

1 年間（50 週）の通常労働時間、残業時間、休日勤務時間を計算し、そこから得られるべき年収と月給を導き出します。

- 平日の最初の 9 時間は**通常労働時間**として時給 1 倍で計算されます；
- 平日の 9 時間を超えた分は**残業時間**として時給 1.5 倍で計算されます；
- 休日は 0 時間を超えた分が**休日勤務時間**として時給 2 倍で計算されます。

### 年間支払い月数

給与が支払われる月数を入力します。12 か月？13.5 か月？14 か月？16 か月？...

### 住宅積立金（住房公積金）の会社側拠出率

下限：5%、上限：12%

多くの人は会社の住宅積立金拠出率について「自分がいくら拠出すれば会社も同額を拠出する」という誤解をしています。

しかし、この値は個人が選んだ拠出率とは関係ありません。会社は通常、固定の拠出率を選んでおり、個人の拠出率に合わせることはありません。

### 住宅積立金（住房公積金）の会社側拠出基準額

下限：2100、上限：33786。地域によって差があります。

多くの会社では、拠出率が低いだけでなく、拠出基準額も低くなっています。

**重要な注意：この値は通常、労働契約上の「基本給」と一致します。労働争議、レイオフ、競業避止義務に関連する補償は、この値によって制限される場合があります！**

### 調整後の月給

住宅積立金の拠出率と拠出基準額に基づいて、得られるべき月給を調整します。
