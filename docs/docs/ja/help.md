# ヘルプ / ヘルプの入手

## Django Ninja を気に入っていただけましたか？

このプロジェクトを気に入っていただけたなら、私たちが正しい方向へ進んでいることを知らせるために、小さなことをひとつお願いできます。

<a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a> で django-ninja にスターを付けてください。<a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

または、この URL を SNS で共有してください：

```
https://django-ninja.cn
```


## 私たちを手伝いたいですか？

プルリクエストはいつでも歓迎します。

ドキュメントの誤字やスペルミスを確認し、プルリクエストを作成するか、issue を立ててください。

Django Ninja の改善に関するご提案があれば、GitHub の issue として作成してください。



## 助けが必要ですか？

遠慮しないでください。<a href="https://github.com/vitalik/django-ninja/issues" target="_blank">GitHub issues</a> にアクセスして、あなたの問題や困りごとを記載してください。できるだけ早く解決できるよう努めます。
