## 👀 前提条件

`django-ninja-crud` パッケージをインストールする前に、以下の依存関係がインストールされていることを確認してください：

- **Python**： このパッケージには Python 3.8 以上が必要です。Python のインストールまたはアップグレードが必要な場合は、[Python 公式サイト](https://www.python.org/downloads/) から行えます。
- **Django**： このパッケージには Django 3.2 以上が必要です。Django のインストールまたはアップグレードが必要な場合は、次のコマンドを使用できます：
- ```shell
  pip install --upgrade django
  ```
- **Django Ninja**： このパッケージには Django Ninja 0.21 以上が必要です。Django Ninja のインストールまたはアップグレードが必要な場合は、次のコマンドを使用できます：
- ```shell
  pip install --upgrade django-ninja
  ```

## ⚒️  `django-ninja-crud` のインストール

前提条件をインストールしたら、pip を使って `django-ninja-crud` をインストールできます：


```shell
pip install django-ninja-crud[testing]
```

インストール中に何か問題が発生した場合は、[お問い合わせください](https://github.com/hbakri)。
