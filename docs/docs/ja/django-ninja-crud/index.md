Django Ninja CRUD ドキュメント
=======================

![Django Ninja CRUD](../img/django-ninja-crud-cover.JPG)


Django Ninja CRUD は、Django Ninja を使った CRUD（Create、Read、Update、Delete）エンドポイントの開発を簡素化する、強力で宣言的ながらやや独断的なフレームワークであり、さらにこのパッケージの妹分である Django REST Testing 🐣 を使ってこれらのエンドポイントをテストするための宣言的でシナリオベースのアプローチも提供します。これにより、よく使われるエンドポイントをクラスベースのビューとして定義し、プロジェクトの規約に合わせて簡単にカスタマイズできるほか、独自のカスタムビューを作成して提供された CRUD ビューと並べて宣言することも容易になり、モジュール性と拡張性が促進されます。このパッケージは、プロジェクト全体で車輪の再発明を行うのではなく、現実世界の問題を解決するという最も重要なことに集中することを推奨しています。


もともと DRF の ModelViewSet に触発された Django Ninja CRUD は、その限界を克服するために進化を遂げ、合成は継承に勝る（composition over inheritance）アプローチを採用して真のモジュール性を実現しました — これは、エンドポイントを作成するためのより広範な宣言的インターフェースに向けた基礎的な一歩です。


継承ベースのビューセットの主な課題：

*     モデルごとの CRUD エンドポイントの一意性： Django Ninja CRUD では、同じモデルに対して複数のエンドポイントを定義でき、バージョニングや代替表現が可能です。
*     カスタマイズの柔軟性： モノリシックなクラスのメソッドをオーバーライドする代わりに、個々のビューが合成と設定を通じてカスタマイズされます。
*     継承階層内の暗黙的な関係： 合成によってビューが分離され、依存関係が減り、再利用性が向上します。
*     新しいエンドポイントのモジュール性の欠如： カスタムエンドポイントの追加に、ビューセット全体をサブクラス化する必要がなくなり、新機能を段階的に導入しやすくなります。

✨ 主な特徴
-------

*     純粋に宣言的： どうやるかではなく、何が欲しいかを宣言することでビューとテストを定義します。
*     比類のないモジュール性： 望む CRUD ビューでビューセットをカスタマイズし、各ビューの挙動をカスタマイズします。
*     拡張の容易さ： 独自のカスタムビューを作成し、提供された CRUD ビューと並べて再利用可能なコンポーネントとして使えます。
*     シナリオベースのテストフレームワーク： シナリオベースのテストフレームワークを活用し、多様なテストケースを宣言的かつ簡潔に定義します。
*     重要なことに集中： 現実世界の問題を解決する時間を増やし、よくある繰り返し作業に費やす時間を減らせます。

> **
> Django Ninja CRUD は単なるツールではなく、Django web アプリケーションの開発とテストにおけるパラダイムシフトです。**
