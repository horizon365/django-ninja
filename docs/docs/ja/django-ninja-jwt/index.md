[Django Ninja REST framework](https://github.com/vitalik/django-ninja) 向けの JSON Web Token 認証プラグインです。

------------------------------------------------------------------------

Ninja JWT は、Django Ninja REST framework 向けの JSON Web Token 認証バックエンドを提供します。
控えめなデフォルト機能セットを提供することで、JWT の最も一般的なユースケースをカバーすることを目指しています。
また、必要な機能が存在しない場合に簡単に拡張できるようにも設計されています。

謝辞
------

このプロジェクトは、Django Ninja REST framework 向けに JSON Web Tokens を実装するために、[SIMPLE JWT](https://github.com/jazzband/djangorestframework-simplejwt) からコードを借用しています。
なお、SIMPLE JWT のライセンスは `license` フォルダに同梱しています。
