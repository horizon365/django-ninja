# v1 での想定される変更点

Django Ninja はすでに数十の企業やビジターに利用されており、ダウンロード統計を見ても成長を続けています。

現時点で、既存のユーザーにコードの変更（あるいはコードの破壊）を強いるような変更を導入することは許容できません。

一方で、初期に決定された一部の判断はうまく機能しませんでした。これらの破壊的変更はバージョン 1.0.0 で導入される予定です。

## v1 で想定される変更点

 - **認証** は、呼び出し可能オブジェクトではなくクラスインターフェースになります（非同期の認証クラスをサポートするため）
 - **レスポンス** が **code/headers/body** をサポートします（一般的なレスポンスクラスのように）
 - **Router のパス** は現在、自動的に **"/" で結合** されます - 場合によってはこれが不要なことがあり、router の prefix はサブフォルダではなくプレフィックスとして機能するようになります。
