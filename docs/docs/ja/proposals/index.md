# 機能拡張提案

機能拡張提案（Enhancement proposals）は、**Django Ninja フレームワーク** への大規模な機能リクエストを提案するための公式な方法です。

提案は、[`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals) 配下に新しいページを追加したプルリクエストを作成するか、[GitHub の issue](https://github.com/vitalik/django-ninja/issues) を立てることで作成できます。

現在の提案を確認してください：
