# Help / Hulp krijgen

## Bevalt Django Ninja je?

Als je dit project waardeert, is er één klein ding dat je kunt doen om ons te laten weten dat we op de goede weg zijn.

Geef django-ninja gewoon een ster op <a href="https://github.com/vitalik/django-ninja" target="_blank"> GitHub</a>. <a href="https://github.com/vitalik/django-ninja" target="_blank">![github star](img/github-star.png)</a>

Of deel deze URL op sociale media:

```
https://django-ninja.cn
```


## Wil je ons helpen?

Pull requests zijn altijd welkom.

Je kunt onze documentatie controleren op typefouten en spelfouten, en een pull request maken of een issue openen.

Als je suggesties hebt om Django Ninja te verbeteren, maak deze dan aan als issues op GitHub.



## Hulp nodig?

Aarzel niet. Ga naar <a href="https://github.com/vitalik/django-ninja/issues" target="_blank">GitHub issues</a> en beschrijf je probleem of de moeilijkheid waar je tegenaan loopt. We zullen proberen deze zo snel mogelijk op te lossen.
