Een JSON Web Token-authenticatieplugin voor het [Django Ninja REST framework](https://github.com/vitalik/django-ninja).

------------------------------------------------------------------------

Ninja JWT biedt een JSON Web Token-authenticatiebackend voor het Django Ninja REST framework.
Het beoogt de meest voorkomende use cases van JWT te dekken door een conservatieve set standaardfuncties aan te bieden.
Het is ook ontworpen om eenvoudig uitbreidbaar te zijn wanneer een vereiste functie ontbreekt.

Dankbetuigingen
------

Dit project leent code van [SIMPLE JWT](https://github.com/jazzband/djangorestframework-simplejwt) om JSON Web Tokens te implementeren voor het Django Ninja REST framework.
Ik heb echter de SIMPLE JWT-licentie opgenomen in de map `license`.
