## 👀 Vereisten

Voordat je het pakket `django-ninja-crud` installeert, moet je controleren of de volgende afhankelijkheden zijn geïnstalleerd:

- **Python**: dit pakket vereist Python 3.8 of hoger. Als je Python moet installeren of upgraden, kan dat via de [officiële Python-website](https://www.python.org/downloads/).
- **Django**: dit pakket vereist Django 3.2 of hoger. Als je Django moet installeren of upgraden, kun je het volgende commando gebruiken:
- ```shell
  pip install --upgrade django
  ```
- **Django Ninja**: dit pakket vereist Django Ninja 0.21 of hoger. Als je Django Ninja moet installeren of upgraden, kun je het volgende commando gebruiken:
- ```shell
  pip install --upgrade django-ninja
  ```

## ⚒️  `django-ninja-crud` installeren

Zodra je de vereisten hebt geïnstalleerd, kun je `django-ninja-crud` installeren met pip:


```shell
pip install django-ninja-crud[testing]
```

Als je problemen ondervindt tijdens de installatie, [neem dan contact met ons op](https://github.com/hbakri).
