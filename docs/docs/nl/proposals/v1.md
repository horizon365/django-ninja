# Mogelijke v1-wijzigingen

Django Ninja wordt al gebruikt door tientallen bedrijven en bezoekers, en uit de downloadstatistieken blijkt dat het groeit.

Op dit punt is het onacceptabel om wijzigingen door te voeren die huidige gebruikers zouden dwingen hun code aan te passen (of deze zouden breken).

Aan de andere kant werkten sommige aanvankelijk genomen beslissingen niet goed. Deze brekende wijzigingen worden geïntroduceerd in versie 1.0.0.

## Waarschijnlijke wijzigingen in v1

 - **Authenticatie** wordt een klasse-interface in plaats van een aanroepbare functie (om async-authenticatoren te ondersteunen)
 - **Response** om **code/headers/body** te ondersteunen (zoals een algemene response-klasse)
 - **Router-paden** worden momenteel automatisch **samengevoegd met "/"** - in sommige gevallen is dit mogelijk niet nodig, aangezien het router-prefix dan als prefix fungeert in plaats van als submap.
