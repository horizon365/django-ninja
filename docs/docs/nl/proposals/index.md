# Verbeteringsvoorstellen

Verbeteringsvoorstellen zijn een formele manier om grote feature-verzoeken in te dienen bij het **Django Ninja framework**.

Je kunt een voorstel indienen door een pull request te openen met een nieuwe pagina onder [`docs/proposals`](https://github.com/vitalik/django-ninja/tree/master/docs/docs/proposals), of door een [issue op github](https://github.com/vitalik/django-ninja/issues) te openen.

Bekijk de huidige voorstellen:

 - [Class-based operations](cbv.md)
